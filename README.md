Nama Tema: Blog pribadi Kurrotul 
Fitur yang tersedia :
1. Header & Navigasi Dinamis (Admin Menu)
2. Layout Grid Artikel
3. Komponen Pendukung / Sidebar Widget
4. Navigasi Halaman (Pagination)
5. Tampilan Detail Artikel
6. Desain Responsif (Mobile-Friendly)
7. Dukungan Plugin Eksternal
Teknologi yang digunakan : PHP, HTML, CSS, XAMPP, WORDPRESS
Petunjuk instalasi:
1. Jalankan aplikasi XAMPP Control Panel, lalu aktifkan module Apache dan MySQL.
2. Buat database baru di http://localhost/phpmyadmin/ (misal: db_wordpress).
3. Selesaikan instalasi dasar WordPress di folder C:\xampp\htdocs\wordpress\.
4. Buka direktori tema WordPress Anda di:C:\xampp\htdocs\wordpress\wp-content\themes\
5. Buat folder baru bernama custom-task-theme (atau nama pilihan Anda).
6. Masukkan file-file utama berikut ke dalam folder tersebut: style.css, functions.php,
7. header.php, index.php, single.php, page.php, sidebar.php, footer.php
8. Masuk ke Admin Dashboard WordPress (http://localhost/wordpress/wp-admin/).
9. Buka menu Tampilan (Appearance) > Tema (Themes).
10. Cari tema yang sudah dibuat, lalu klik Aktifkan (Activate).
11. Buka menu Tampilan (Appearance) > Menu:
12. Buat menu baru, tambahkan halaman yang diinginkan (misal: Beranda, Tentang, Kontak).
13. Centang opsi lokasi Primary Menu, lalu klik Simpan Menu.
14. Pengaturan Pagination: Pergi ke Pengaturan (Settings) > Membaca (Reading), ubah Laman
15. situs menampilkan paling banyak menjadi 2 atau 4 artikel agar fitur pagination aktif.
16. Instalasi Plugin: Pergi ke Plugin > Tambah Baru (Add New), cari dan install plugin
17. Contact Form 7 dan FooGallery untuk melengkapi fitur formulir dan galeri foto.
